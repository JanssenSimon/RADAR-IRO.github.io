# 20 juin 2025

\tableofcontents

Le RADAR est silencieux, mais il n'est pas mort.

Je travaille trop peu et depuis bien trop longtemps sur une refonte du site Web
du RADAR. Mon objectif est de passer à l'utilisation d'un générateur de site
statique. Ceci faciliterait le travail de potentielles collaboratrices car
elles n'auront qu'à écrire leurs ajouts en markdown.

Le générateur de site statique pour lequel j'ai opté s'appelle
[Franklin.jl](https://franklinjl.org/). Il est écrit en *julia*. Il permet
l'insertion d'équations mathématiques dans les pages en utilisant les balises
`$` comme dans $\LaTeX$.

$$\Delta{v}=v_e\ln{\frac{m_0}{m_f}}$$

Franklin.jl permet aussi l'ajout de bloques de code avec coloration. Dans
certains cas, ces bloques peuvent même être executés sur la page Web générée.

Malgré toutes ces bonnes choses, en m'en servant, j'ai découvert certains
comportements étranges. Je crois qu'il y a un nombre de bogues et/ou
d'innefficacités dans Franklin.jl. Pour l'instant je suis prêt à les tolérer. Je
prévois cependant investiguer davantage ce logiciel dans l'espoir de
l'améliorer. Je vous tiendrai au courant si je trouve dequoi d'intéressant.

Choisir un générateur de site c'est bien beau, mais c'est surtout le contenu du
site qui importe. Je suis en train de convertir tous les anciens fichier HTML en
markdown. Le plus gros du travail (comprendre comment utiliser Franklin et
écrire quelques petites fonctionnalités pour l'affichage de certaines pages) est
fait. Attendez vous à voir plus de billets dans ce blogue dans les prochaines
semaines.

\- Simon Janssen VA2SZM, co-responsable du RADAR
